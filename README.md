**[phev2mqtt-nxt](https://github.com/athomasse/phev2mqtt-nxt)** connects a Mitsubishi
Outlander PHEV to MQTT and Home Assistant over the car's own WiFi: battery, charging,
doors and climate in Home Assistant, and pre-heating the car from your phone. A fork of
[buxtronix/phev2mqtt](https://github.com/buxtronix/phev2mqtt) with Debian packages for
every Raspberry Pi, a web interface, connection and WiFi status, and a hardened service.

### 🏠 Homelab

At home I run a homelab that I treat like production: virtual machines and containers on
Proxmox, Raspberry Pis for the odd jobs, everything set up with Ansible and kept in Git
on a self-hosted Forgejo, and Home Assistant with MQTT running the house.
